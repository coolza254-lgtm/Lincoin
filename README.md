# Lincoin

แอป Android สำหรับเรียนภาษาญี่ปุ่นใช้เองส่วนตัว ตั้งแต่ระดับเริ่มต้นจนถึง N1 เน้นท่องศัพท์และเรียนไวยากรณ์ด้วยระบบทบทวนแบบเว้นระยะ (FSRS) มีเกมเล็กน้อยด้วยเหรียญ **ลินคอย (Lincoin)**

- ใช้ออฟไลน์เป็นหลัก ใช้เน็ตเฉพาะบางฟีเจอร์
- วัดผลจากข้อมูลการตอบจริง ไม่ให้คะแนนตามความรู้สึก
- ใช้เนื้อหาจากแหล่งที่มีสัญญาอนุญาตชัดเจน และแสดงเครดิตเสมอ
