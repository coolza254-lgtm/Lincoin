# Lincoin

แอป Android สำหรับเรียนภาษาญี่ปุ่นใช้เองส่วนตัว ตั้งแต่ระดับเริ่มต้นจนถึง N1 เน้นท่องศัพท์และเรียนไวยากรณ์ด้วยระบบทบทวนแบบเว้นระยะ (FSRS) มีเกมเล็กน้อยด้วยเหรียญ **ลินคอย (Lincoin)**

- ใช้ออฟไลน์เป็นหลัก ใช้เน็ตเฉพาะบางฟีเจอร์
- วัดผลจากข้อมูลการตอบจริง ไม่ให้คะแนนตามความรู้สึก
- ใช้เนื้อหาจากแหล่งที่มีสัญญาอนุญาตชัดเจน และแสดงเครดิตเสมอ

สถานะ: **เฟส 1 เสร็จ (core engines)** เอกสารทั้งหมดอยู่ที่ [`docs/`](docs/README.md)

## โครงสร้าง repo

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `docs/` | เอกสารออกแบบ |
| `packages/lincoin_core/` | เอนจินหลัก (FSRS, ให้คะแนน, ลินคอย, สถิติ) พร้อมชุดทดสอบ |
| `design/` | Design tokens (ธีม, สี, ฟอนต์) และตัวตรวจคอนทราสต์ |

## รันทดสอบ

ต้องมี [Dart SDK](https://dart.dev/get-dart) 3.5 ขึ้นไป

```sh
cd packages/lincoin_core && dart pub get && dart test
dart run design/check_tokens.dart
```
