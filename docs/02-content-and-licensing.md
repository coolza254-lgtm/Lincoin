# 02 เนื้อหา สัญญาอนุญาต และคุณภาพ

> ข้อมูลสัญญาอนุญาตด้านล่างต้องตรวจซ้ำกับหน้าทางการของแต่ละแหล่งก่อนดึงข้อมูลจริงทุกครั้ง และบันทึกผลลงตาราง `sources` นี่ไม่ใช่คำปรึกษาทางกฎหมาย

## สิ่งที่ไม่ใช้
- เนื้อหาจากหนังสือเรียนและแอปเชิงพาณิชย์
- สำรับ Anki ที่ไม่ทราบที่มา/สัญญาอนุญาต
- การ scrape เว็บ (Jisho, Weblio ฯลฯ)
- ภาพ/เสียงที่ลิขสิทธิ์ไม่ชัด (ใช้ภาพที่วาดเองหรือ CC0 เท่านั้น)

## ข้อเท็จจริง vs การอธิบาย

| ประเภท | ที่มา | ห้าม |
|---|---|---|
| คำอ่าน, ฟุริงานะ, ชนิดคำ, ระดับ | ไฟล์ต้นทางเท่านั้น | สร้างจากความจำของ AI |
| ประโยคตัวอย่างภาษาญี่ปุ่น | Tatoeba | แต่งประโยคเอง |
| คำแปลไทย, หมายเหตุการใช้ | AI แปลโดยยึด gloss ของ JMdict + ตรวจ | แปลลอยๆ ไม่มีฐาน |
| คำอธิบายไวยากรณ์ไทย | AI เขียน, ตรวจเทียบแหล่งอ้างอิง | คัดลอกข้อความจากแหล่งที่ไม่อนุญาต |

## ขั้นตอนสร้าง content.db (`tools/content_builder`)

1. ดาวน์โหลดไฟล์ต้นทาง บันทึก URL, เวอร์ชัน, วันที่, checksum
2. แปลงเป็นตาราง (ไม่มีการแก้ไฟล์ด้วยมือ ทุกอย่างรันซ้ำได้)
3. รวมคำแปลไทยจาก `tools/translations/` (แยกไฟล์จากข้อมูลต้นทาง)
4. **ตรวจอัตโนมัติ (build ล้มถ้าไม่ผ่าน)**
   - ทุกแถวมี `source_id` ที่มี license และข้อความเครดิต
   - ทุกประโยคจาก Tatoeba มีชื่อผู้เขียน
   - ID ไม่ซ้ำและ ID เก่าไม่หายโดยไม่มีบันทึก
5. สร้างหน้าเครดิตอัตโนมัติจากตาราง `sources`

หากสภาพแวดล้อมดาวน์โหลดไฟล์ต้นทางไม่ได้ ให้หยุดและแจ้ง ห้ามใช้ข้อมูลจากความจำแทน

## คุมคุณภาพคำแปลไทย

1. แปลเป็นชุดตามระดับ โดยส่ง gloss อังกฤษ + คำอ่าน + ชนิดคำ + ประโยคตัวอย่างไปด้วย
2. **แปลย้อนกลับ** ไทย→อังกฤษ แล้วเทียบความหมายกับ gloss เดิม ไม่ตรงให้ติดธง `flagged`
3. **ความสม่ำเสมอ** คำ/ความหมายเดียวกันต้องแปลเหมือนกันทุกที่
4. **Audit แบบสุ่ม** 200–300 รายการต่อระดับ ตรวจโดยคน เพื่อวัดอัตราผิดจริง
5. สถานะต่อความหมาย: `draft → auto_checked → verified` หรือ `flagged`
6. ในแอปมีปุ่ม **รายงาน/แก้คำแปล** เก็บการแก้ไขใน `translation_overrides` ซึ่งไม่ถูกทับเมื่ออัปเดตเนื้อหา

## ไวยากรณ์
- รายการหัวข้อ N5–N1 (ประมาณ 500–600 หัวข้อ) เรียบเรียงเอง ตั้ง ID ตายตัว
- ประโยคตัวอย่างค้นจาก Tatoeba ด้วยรูปแบบที่ตรงกับหัวข้อ แล้วตรวจว่าใช้ไวยากรณ์นั้นจริง
- N2–N1 มีความเสี่ยงอธิบายคลาดเคลื่อนมากกว่า ต้อง audit เข้มกว่า

## Share-Alike
แอปออก release บน repo public (เพื่อปุ่มอัปเดตในแอป) จึงนับเป็นการเผยแพร่ `content.db` จะเผยแพร่ภายใต้ CC BY-SA 4.0 พร้อมเครดิตครบ และห้ามคัดลอกข้อความจากแหล่ง NC (เช่น Tae Kim) ลงในเนื้อหา ดู [10-updates.md](10-updates.md#ผลต่อเรื่องสัญญาอนุญาต)

## สถานะการตรวจสัญญาอนุญาต (เฟส 2, 2026-09-30)

| แหล่ง | ยืนยันจาก | ผล |
|---|---|---|
| JMdict / KANJIDIC2 | หน้าใบอนุญาต EDRDG (ผ่านผลค้นหา) | CC BY-SA 4.0, ใช้ในแอปได้รวมเชิงพาณิชย์ ต้องแจ้งการใช้และแหล่งที่มาในเอกสาร/เว็บ/แอป |
| JmdictFurigana | README ของ repo (อ่านตรง) | "same licence as JMdict" (CC BY-SA), โค้ดเป็น MIT |
| yomitan-jlpt-vocab | ไฟล์ LICENSE.txt ของ repo (อ่านตรง) | CC BY-SA 4.0 และระบุที่มาเป็น Tanos (CC BY) |
| Tanos | README ของโปรเจกต์ที่ใช้ข้อมูล (อ่านตรง) + ผลค้นหา | CC BY, Jonathan Waller |
| Tatoeba | วิกิ/หน้าเงื่อนไขของ Tatoeba (ผ่านผลค้นหา) | CC BY 2.0 FR (บางประโยค CC0), ต้องระบุชื่อผู้เขียน |

หน้าเว็บ EDRDG, Tanos และ Tatoeba เข้าจากเครื่องพัฒนานี้โดยตรงไม่ได้ (ถูกนโยบายเครือข่ายบล็อก) จึงยืนยันผ่านผลค้นหาและ repo ที่อ้างถึง การดาวน์โหลดข้อมูลจริงทำบน GitHub Actions

**วิธีเลือกประโยคตัวอย่าง:** ใช้ดัชนีคำของ Tatoeba (`jpn_indices`) ต้องมีคำแปลอังกฤษและชื่อผู้เขียนทั้งสองภาษา เลือกประโยคที่ถูกทำเครื่องหมายว่าดีก่อน แล้วประโยคสั้น (≤ 25 ตัวอักษร) คำที่สะกดซ้ำกับคำอื่นใน JMdict ต้องมีคำอ่านกำกับในดัชนี กันจับผิดคำ (เช่น 方 かた/ほう)
