# 07 การวัดผลและความก้าวหน้า

ทุกตัวเลขคำนวณจาก `review_log` / `practice_log` ด้วยเกณฑ์ตายตัวใน config เปลี่ยนเกณฑ์แล้วคำนวณย้อนหลังได้ทั้งหมด แยกตามโหมด (ศัพท์ / ไวยากรณ์)

## สถานะรายการ

| สถานะ | เงื่อนไข |
|---|---|
| ใหม่ | ยังไม่แนะนำ |
| กำลังเรียน | อยู่ใน learning/relearning steps |
| ทบทวน | อยู่ในคิว FSRS |
| **เชี่ยวชาญ** | S ≥ 21 วัน **และ** reps ≥ 3 **และ** การตอบล่าสุดไม่ใช่ Again |

- "เชี่ยวชาญ" เป็นสถานะ ณ ปัจจุบัน ตอบผิดภายหลังก็กลับเป็น "ทบทวน" เก็บ `first_mastered_at` ไว้
- ศัพท์ 1 คำ เชี่ยวชาญ = ทุก facet ที่เปิดใช้เชี่ยวชาญ
- ไวยากรณ์ 1 หัวข้อ เชี่ยวชาญ = การ์ด cloze ของหัวข้อนั้นเชี่ยวชาญ

## ตัวชี้วัดหลัก

| ตัวชี้วัด | นิยาม |
|---|---|
| **ศัพท์ที่น่าจะจำได้** | Σ R ของรายการที่เรียนแล้ว ณ ตอนนี้ (ลดลงจริงถ้าหยุดเรียน) |
| **Coverage รายระดับ** | Σ R ของรายการในระดับ ÷ จำนวนรายการทั้งระดับ (ที่ยังไม่เรียนนับ 0) |
| เชี่ยวชาญรายระดับ | เช่น N5: 412 / 800 |
| Retention จริง | สัดส่วนตอบถูกในการทบทวนที่ถึงกำหนด (ไม่นับ learning) รายวัน/สัปดาห์/เดือน |
| Calibration | R ที่ทำนาย vs อัตราถูกจริง แบ่งช่วง |
| ภาระ | ค้างวันนี้ + พยากรณ์ 7/30 วัน |
| เวลาเรียน | active seconds (ไม่นับช่วงไม่มีการตอบเกิน 60 วินาที) |
| ความเร็ว | มัธยฐานเวลาตอบต่อรูปแบบโจทย์ แนวโน้ม |
| จุดอ่อน | leech, รายการ R ต่ำสุด, หมวด/ชนิดคำที่ผิดบ่อย |
| โหมดฝึก | จำนวนข้อ, ความแม่น, จุดอ่อนที่ดีขึ้น (แยกจากสถิติหลัก) |
| ลินคอย | รายรับ-รายจ่ายตามแหล่ง |

**คำเตือนในแอป:** Coverage ศัพท์ไม่เท่ากับความพร้อมสอบ JLPT (ข้อสอบวัดการฟัง/อ่านด้วย และระดับเป็นค่าประมาณ) จึงใช้คำว่า "ความครอบคลุมศัพท์ระดับ N5" ไม่ใช่ "พร้อมสอบ N5"

## หน้าสถิติ (โครง)
1. **ภาพรวม:** ศัพท์ที่น่าจะจำได้, หัวข้อไวยากรณ์ที่เชี่ยวชาญ, ค้างวันนี้
2. **ระดับ:** แถบ Coverage N5→N1 ของทั้งสองโหมด
3. **แนวโน้ม:** กราฟรายวัน/สัปดาห์/เดือน (รายการใหม่, ทบทวน, retention, เวลา)
4. **ตารางความร้อน (heatmap)** กิจกรรมรายวัน (แสดงเฉยๆ ไม่ใช่ streak)
5. **จุดอ่อน:** รายการ leech และ R ต่ำ ปุ่มส่งไปโหมดฝึก
6. **ความน่าเชื่อถือ:** กราฟ calibration, เวอร์ชันพารามิเตอร์ FSRS
7. **รายละเอียดรายคำ:** ประวัติการตอบทุกครั้ง, S/D/R, due ถัดไป
