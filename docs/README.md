## บันทึกการตัดสินใจ

| หัวข้อ | ตัดสินใจ |
|---|---|
| แพลตฟอร์ม | Android เป็นหลัก, Native App |
| เทคโนโลยี | Flutter + SQLite (Drift) |
| การเชื่อมต่อ | ออฟไลน์เป็นหลัก ใช้เน็ตบางฟีเจอร์ |
| ขอบเขตเนื้อหา | ศัพท์และไวยากรณ์ ตั้งแต่เริ่มต้น (คานะ) ถึง N1 |
| ตัดออก | การคัดลายมือ/ลำดับขีด, การตรวจการเขียน |
| โหมดหลัก | ท่องศัพท์ และ ไวยากรณ์ แยกกัน (คิวและสถิติแยก, เหรียญกระเป๋าเดียว) |
| ภาษาคำอธิบาย | ไทย (เก็บต้นฉบับอังกฤษจาก JMdict ไว้อ้างอิง) |
| แหล่งข้อมูล | JMdict, JmdictFurigana, รายการ JLPT ของ Tanos, Tatoeba, KANJIDIC2 (ถ้าต้องใช้) |
| SRS | FSRS แยกตัวจัดตารางต่อโหมด, ระดับความจำที่ต้องการปรับได้ |
| ศัพท์ใหม่ต่อวัน | ปรับได้ |
| Streak | **ไม่มี** ตัดระบบ streak ออกทั้งหมด |
| ระบบหัวใจ | **ไม่มี** |
| สกุลเงิน | ลินคอย (Lincoin) |
| ที่ใช้เหรียญ | ร้านรางวัลจริงที่ตั้งเอง, โหมดท้าทาย (เดิมพัน) |
| ที่มาเหรียญเพิ่ม | โหมดฝึก เล่นได้ไม่จำกัด (ผลตอบแทนลดลงตามปริมาณต่อวัน) |
| สไตล์ UI | โมเดิร์นมินิมอลแบบ Apple ผสมความน่ารัก (รายละเอียดคุยแยก) |

### ค่าเริ่มต้นที่เลือกให้ (ยังไม่ได้ยืนยัน เปลี่ยนได้)
- โหมดท้าทายใช้ **ระดับความยาก 4 ขั้น ตัวคูณตายตัว**
- โหมดฝึกใช้ **ผลตอบแทนลดลง 3 ระดับต่อวัน**
- ราคาร้านรางวัลจริงเป็นตัวอย่าง รอคุณตั้งรายการจริง
