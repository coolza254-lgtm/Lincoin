# 09 UI/UX

> สถานะ: ใช้เป็นแนวทางเวอร์ชันแรก (mockup: [Lincoin UI Mockup](https://claude.ai/artifact/44bxwccwajcSkX8fU5mqkQ)) ออกแบบให้เปลี่ยนได้เรื่อยๆ ตามหัวข้อ "รองรับการเปลี่ยน UI"

## แนวทาง
**"สะอาดแบบ Apple, อบอุ่นแบบของเล่น"**
- เรียบก่อนน่ารัก: พื้นที่ว่างเยอะ ตัวอักษรใหญ่ ลำดับความสำคัญชัด
- หน้าจอหนึ่งทำงานเดียว ระหว่างเรียนเห็นแค่โจทย์
- ไม่ลงโทษ: ตอบผิดใช้สีส้มอ่อน + ไอคอน ไม่ใช้สีแดงหรือเสียงดุ
- เด็กใช้ได้: ปุ่มใหญ่ (≥ 44 px), ข้อความสั้น, ไอคอนมีคำกำกับ, ไม่มีเมนูซ้อนลึก
- **ไม่มีมาสคอต**

## ธีม (ผู้ใช้เลือกได้)
| ธีม | จุดประสงค์ |
|---|---|
| มัทฉะ (ค่าเริ่มต้น) | เขียวอมฟ้า สบายตา |
| ซากุระ | ชมพูอ่อน |
| **ขาวดำ (โฟกัส)** | ตัดสีทั้งหมด รวมถึงสี Lincoin และสีถูก/ผิด ใช้ไอคอนและน้ำหนักตัวอักษรแทน เพื่อลดสิ่งเร้า |
| มืด | สำหรับกลางคืน |

ทุกธีมใช้ชุดโทเค็นเดียวกัน: `bg, surface, ink, muted, line, track, accent, onAccent, accentSoft, coin, coinSoft, good, goodSoft, warn, warnSoft` สีทุกคู่ข้อความ/พื้นต้องผ่านคอนทราสต์ 4.5:1 และสถานะถูก/ผิดต้องสื่อด้วยไอคอนด้วย ไม่ใช่สีอย่างเดียว

## ตัวอักษร
| ใช้กับ | ฟอนต์ (OFL) |
|---|---|
| ภาษาไทย / UI | IBM Plex Sans Thai |
| ภาษาญี่ปุ่น | Zen Maru Gothic (กลม น่ารัก) |

คำญี่ปุ่นในโจทย์ 48–64 pt ฟุริงานะแสดงด้วย `ruby`

## ภาษา UI
ไทยล้วน (เวอร์ชันแรก) เก็บข้อความทั้งหมดในไฟล์แปล (ARB) เพื่อเพิ่มภาษาภายหลังได้

## รูปทรงและการเคลื่อนไหว
- มุมโค้ง: การ์ดใหญ่ 24–28 px, ปุ่ม 16–18 px, ชิป 999 px
- เงาบางสองชั้น ไม่มีเส้นขอบหนา
- แอนิเมชันสั้น (150–250 ms) ตั้ง "ลดแอนิเมชัน" ได้, haptic เบาเมื่อตอบถูก

## การนำทาง
Tab bar ล่าง 4 แท็บ: **หน้าหลัก · ฝึก & ท้าทาย · สถิติ · ร้าน** ตั้งค่า/เครดิต/สำรองข้อมูลอยู่ที่ไอคอนมุมบนของหน้าหลัก

## หน้าจอ (ตาม mockup)
| หน้า | องค์ประกอบหลัก |
|---|---|
| หน้าหลัก | ยอด Lincoin, การ์ดท่องศัพท์ (ค้าง/ใหม่/เวลาโดยประมาณ + ปุ่มเริ่ม), การ์ดไวยากรณ์, แถบความครอบคลุมระดับปัจจุบัน |
| ทบทวน: โจทย์ | ปุ่มปิด, แถบความคืบหน้า, ป้ายชนิดโจทย์, คำใหญ่, ช่องตอบ (โรมาจิแปลงเป็นคานะ), ปุ่ม ตรวจคำตอบ / ไม่รู้ / ตอบแบบเดา ไม่มีปุ่มให้คะแนนตัวเอง |
| ทบทวน: เฉลย | แถบผลลัพธ์ + Lincoin ที่ได้, คำพร้อมฟุริงานะ, ปุ่มเสียง, ความหมายไทย, ชนิดคำ/ระดับ, ประโยคตัวอย่างพร้อมเครดิต, รายงานคำแปล |
| บทเรียนไวยากรณ์ | การ์ดทีละส่วน: ความหมาย → วิธีประกอบ → ตัวอย่าง → อย่าสับสนกับ แล้วจบด้วยโจทย์ลองทำ |
| ฝึก & ท้าทาย | สลับ ฝึก/ท้าทาย, เลือกชาเลนจ์, ระดับ 4 ขั้นพร้อมตัวคูณ, เงื่อนไขชนะ, ตัวปรับเดิมพัน (เพดาน 30%), สรุปได้/เสีย |
| ร้าน | ยอด Lincoin + รายได้เฉลี่ย, รายการรางวัลที่ตั้งเอง (ราคา, แถบความคืบหน้า, คูลดาวน์, เงื่อนไข), ประวัติการแลก |
| สถิติ | สลับ ศัพท์/ไวยากรณ์, ศัพท์ที่น่าจะจำได้, retention จริง vs เป้า, เชี่ยวชาญ, เวลาเรียน, Coverage N5–N1, จุดอ่อน → ฝึก |

## ภาษาญี่ปุ่นเฉพาะ
- ฟุริงานะ: แสดงเสมอ / ซ่อนคำที่เชี่ยวชาญแล้ว / ซ่อนทั้งหมด
- การพิมพ์: แปลงโรมาจิเป็นคานะในช่องตอบเอง ไม่ต้องติดตั้งคีย์บอร์ดญี่ปุ่น
- เสียง: แตะเพื่อฟัง, ตั้งเล่นอัตโนมัติได้

## การเข้าถึง
รองรับขนาดตัวอักษรระบบ, คอนทราสต์ WCAG AA, ไม่สื่อด้วยสีอย่างเดียว, ลดแอนิเมชันได้, ทุกปุ่มไอคอนมีป้ายสำหรับ screen reader

## รองรับการเปลี่ยน UI ในอนาคต

หลักการ: **เปลี่ยนหน้าตาได้โดยไม่แตะตรรกะการเรียน และเปลี่ยนจุดเดียวแล้วมีผลทั้งแอป**

| ชั้น | อยู่ที่ | เปลี่ยนอย่างไร |
|---|---|---|
| Design tokens (สี, ธีม, ฟอนต์, ขนาด, มุมโค้ง, ระยะห่าง, ความเร็วแอนิเมชัน) | [`design/tokens.json`](../design/tokens.json) | แก้ไฟล์เดียว → สร้างเป็น `ThemeExtension` ของ Flutter อัตโนมัติ (ไม่เขียนค่าสีลงในหน้าจอเด็ดขาด) |
| ตัวตรวจอัตโนมัติ | [`design/check_tokens.dart`](../design/check_tokens.dart) | ทุกธีมต้องมีโทเค็นครบชุดเดียวกัน และคู่ข้อความ/พื้นผ่านคอนทราสต์ WCAG AA ไม่ผ่าน = build ล้ม |
| Component library | `app/lib/ui/` | ปุ่ม, การ์ด, ชิป, แถบความคืบหน้า, tab bar สร้างครั้งเดียว หน้าจอประกอบจากชิ้นเหล่านี้เท่านั้น |
| หน้าจอ | `app/lib/features/` | อ่านข้อมูลจาก state (Riverpod) ไม่เรียก engine หรือฐานข้อมูลตรง จึงรื้อ layout ได้โดยไม่กระทบตรรกะ |
| ข้อความ UI | ไฟล์ ARB | แก้คำ/เพิ่มภาษาโดยไม่แตะโค้ด |
| ตรรกะการเรียน | `packages/lincoin_core` | ไม่มี Flutter เลย เปลี่ยน UI ทั้งหมดแล้วชุดทดสอบของ core ยังรับประกันพฤติกรรมเดิม |

แนวปฏิบัติเพิ่มเติม
- เพิ่มธีมใหม่ = เพิ่ม 1 ก้อนใน `tokens.json` (ไม่ต้องแก้โค้ด)
- ธีมที่ผู้ใช้เลือกเก็บใน `settings` ถ้าธีมถูกลบในเวอร์ชันใหม่ ให้กลับไปใช้ `defaultTheme`
- ทดสอบหน้าจอด้วย golden tests ในทุกธีม เพื่อเห็นผลกระทบเมื่อเปลี่ยนโทเค็น
- ฟีเจอร์ใหม่ที่ยังไม่นิ่งซ่อนหลัง feature flag ใน `settings`
