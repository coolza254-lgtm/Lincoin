# 05 โหมดการเรียน

| โหมด | ป้อน FSRS | ได้ลินคอย | จำกัดจำนวน |
|---|---|---|---|
| ท่องศัพท์ | ✔ | ✔ | ตามตาราง + ศัพท์ใหม่/วัน |
| ไวยากรณ์ | ✔ | ✔ | ตามตาราง + หัวข้อใหม่/วัน |
| ฝึก | ✘ | ✔ (ลดลงตามปริมาณ) | ไม่จำกัด |
| ท้าทาย | ✘ | เดิมพัน | ไม่จำกัด (เพดานเดิมพัน) |

## 1. โหมดท่องศัพท์

**เส้นทาง:** คานะ (ฮิรางานะ → คาตาคานะ) → N5 → N4 → N3 → N2 → N1

**การแนะนำคำใหม่:** การ์ดแสดงคำ, ฟุริงานะ, คำอ่าน, เสียง, ความหมายไทย, ชนิดคำ, ประโยคตัวอย่าง 1–2 ประโยค พร้อมเครดิตผู้เขียนประโยค แล้วเข้า learning steps

**Facet**
| facet | โจทย์ | ค่าเริ่มต้น |
|---|---|---|
| `recog` | เห็นคำญี่ปุ่น → เลือกความหมายไทย / พิมพ์คำอ่าน | เปิด |
| `recall` | เห็นความหมายไทย → พิมพ์คำอ่าน (คานะ/โรมาจิ) หรือเลือกคำ | เปิด |
| `listen` | ฟังเสียง → เลือกความหมาย | ปิด |
| `kana` | ตัวอักษร → โรมาจิ | เฉพาะคานะ |

## 2. โหมดไวยากรณ์

**เส้นทาง:** N5 → N1 ตาม `grammar_points.ord`

**บทเรียน 1 หัวข้อ:** ความหมาย, วิธีประกอบ, หมายเหตุ, เทียบกับหัวข้อคล้ายกัน, ประโยคตัวอย่าง 3–5 ประโยค

**การ์ด:** `cloze` 1 ใบต่อหัวข้อ แต่ละครั้งที่ทบทวนสุ่มประโยคคนละประโยคจากชุดของหัวข้อนั้น (กันจำประโยคแทนไวยากรณ์)

**รูปแบบโจทย์**
- เลือกรูปไวยากรณ์ที่เติมในช่องว่าง (ตัวลวงจาก `similar_ids` ก่อน)
- เรียงคำให้เป็นประโยค (เฉพาะโหมดฝึก)
- ความหมายไทยของประโยค → เลือกประโยคญี่ปุ่นที่ถูก

## 3. โหมดฝึก (เล่นไม่จำกัด)

**แหล่งโจทย์ (ปรับสัดส่วนได้)**
- เพิ่งเรียน (introduced ใน 7 วัน)
- จุดอ่อน: R ต่ำ, leech, ผิดบ่อยใน practice
- สุ่มจากที่เรียนแล้วทั้งหมด

**รูปแบบ:** รอบละ 10 ข้อ ผสมรูปแบบโจทย์ (เลือก, พิมพ์, ฟัง, เติมคำ, เรียงประโยค, จับคู่) มีคอมโบ จบรอบแสดงสรุปและจุดอ่อนที่ดีขึ้น

**ใช้เฉพาะรายการที่เคยเรียนแล้ว** ไม่ใช้โหมดนี้เพิ่มคำใหม่

บันทึกลง `practice_log` เท่านั้น ใช้จัดอันดับจุดอ่อนและสถิติโหมดฝึก

## 4. โหมดท้าทาย (เดิมพันลินคอย)

**หลักการ:** ผลขึ้นกับฝีมือเท่านั้น ไม่มีสุ่มโชค เป็นเหรียญในแอป ไม่ใช่เงินจริง

**ขั้นตอน:** เลือกชาเลนจ์ → เลือกระดับ → ดูเกณฑ์ที่ต้องทำ → ตั้งเดิมพัน → เล่น → ชนะได้ `stake × multiplier` (รวมทุนคืน), แพ้/ยอมแพ้เสียเดิมพัน

**ชาเลนจ์**
| ชื่อ | กติกา (ระดับปกติ) |
|---|---|
| สปีดรอบ | ตอบ N ข้อใน 60 วินาที ถูก ≥ X% |
| ไร้ที่ติ | ถูกต่อเนื่อง N ข้อ |
| ล่าจุดอ่อน | 10 ข้อจากจุดอ่อน ถูก ≥ X% |
| บอสไวยากรณ์ | 25 ข้อผสมหมวดที่เลือก ถูก ≥ X% |
| สัปดาห์ขยัน | เคลียร์การ์ดค้างของวันได้ ≥ 5 จาก 7 วันถัดไป |

**ระดับและตัวคูณ (ตายตัว)**
| ระดับ | ตัวคูณ | โอกาสชนะเป้าหมาย |
|---|---|---|
| ง่าย | 1.3× | ~75% |
| ปกติ | 2.0× | ~50% |
| ยาก | 3.5× | ~30% |
| โหด | 6.0× | ~15% |

**เกณฑ์ปรับตามฝีมือ:** ค่า N และ X ของแต่ละระดับคำนวณจากความแม่นและความเร็วของ 20 รอบล่าสุด (practice + challenge) ให้โอกาสชนะใกล้ค่าเป้าหมาย ตัวคูณแต่ละระดับตั้งไว้ให้ค่าคาดหวังติดลบเล็กน้อย จึงชนะระยะยาวต้องเก่งขึ้นจริง

**กติกาความปลอดภัย**
- เดิมพันขั้นต่ำ 20, สูงสุด min(30% ของยอดคงเหลือ, 1,000)
- มีชาเลนจ์ค้างได้ครั้งละ 1 (ยกเว้น "สัปดาห์ขยัน")
- ออกกลางคัน = ยอมแพ้
- ผลการเล่นไม่ป้อน FSRS
- เกณฑ์ใช้ข้อมูลหลายรอบ การจงใจแพ้เพื่อลดเกณฑ์จึงไม่คุ้ม
