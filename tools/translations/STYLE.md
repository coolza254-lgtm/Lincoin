# แนวทางแปลไทย (Lincoin)

## หลักการ
1. **แปลจากความหมาย ไม่ใช่ตัวอักษร** ยึด gloss อังกฤษของ JMdict เป็นฐาน และดูคำญี่ปุ่น ชนิดคำ และป้ายกำกับประกอบ
2. **กระชับแบบพจนานุกรม** คำหรือวลีสั้น ไม่ใช่ประโยค
3. **ความหมายใกล้เคียงคั่นด้วย `, `** และความหมายย่อยที่ต่างกันชัดคั่นด้วย `; ` (ตามต้นฉบับ)
4. **ไม่เติมความหมายที่ต้นฉบับไม่มี** และไม่ตัดความหมายหลักทิ้ง ถ้าต้นฉบับมีคำพ้องหลายคำที่แปลไทยได้คำเดียวกัน ให้รวมเป็นคำเดียว
5. **คำอธิบายในวงเล็บ** แปลด้วย เช่น `foot; paw (of an animal)` → `เท้า; อุ้งเท้า (ของสัตว์)`

## ตามชนิดคำ
| ชนิด | แนวทาง | ตัวอย่าง |
|---|---|---|
| กริยา (`v*`) | ใช้กริยาไทยล้วน ไม่ใส่ "การ" | to meet → พบ, เจอ |
| คุณศัพท์ -i / -na | ใช้คำคุณศัพท์ไทย | cheap → ถูก (ราคา) |
| คำนาม | คำนามไทยที่ใช้จริง | library → ห้องสมุด |
| คำนามที่ใช้กับ する (`vs`) | แปลเป็นคำนาม ส่วนความหมายเมื่อเป็นกริยาไว้ใน note ถ้าจำเป็น | laundry → การซักผ้า |
| คำช่วย / สำนวน | อธิบายหน้าที่สั้นๆ | ― |
| คำยืม (カタカナ) | ใช้คำไทยที่ใช้จริง ถ้าไทยก็ทับศัพท์ ให้ทับศัพท์ | restaurant → ร้านอาหาร |

## `note` (หมายเหตุ)
ใช้เมื่อจำเป็นเท่านั้น สั้นไม่เกินหนึ่งประโยค:
- ระดับภาษา: คำสุภาพ (`hon`), คำถ่อมตัว (`hum`), ภาษาพูด (`col`), ภาษาเขียน
- ข้อควรระวังที่คนไทยมักสับสน (เช่น 貸す/借りる)
- ห้ามใส่ความรู้ที่ไม่แน่ใจ

## ประโยคตัวอย่าง
- แปลจากภาษาญี่ปุ่นเป็นหลัก ใช้คำแปลอังกฤษช่วยยืนยันความหมาย
- ภาษาไทยเป็นธรรมชาติ ระดับสุภาพตามต้นฉบับ (です/ます → ครับ/ค่ะ ไม่ต้องใส่ ใช้ภาษากลางๆ)
- ชื่อคนและชื่อสถานที่ทับศัพท์

## ห้าม
- ห้ามคัดลอกคำแปลจากพจนานุกรมหรือเว็บที่มีลิขสิทธิ์
- ห้ามแปลโดยไม่มีต้นฉบับ gloss (ต้องมี `en` ทุกแถว)

## สถานะ
- `draft` = แปลแล้ว ยังไม่ผ่านตรวจอัตโนมัติ
- `auto_checked` = ผ่าน `qa.py`
- `flagged` = มีคำเตือนจาก `qa.py` หรือต้นทางเปลี่ยน ต้องดูอีกครั้ง
- `verified` = คนตรวจแล้วใน audit
