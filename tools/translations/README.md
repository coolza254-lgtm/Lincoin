# translations

คำแปลไทยของเนื้อหา แยกจากข้อมูลต้นทาง ตัวสร้าง `content.db` รวมเข้าไปตอน build

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `senses/<level>.jsonl` | ความหมายของศัพท์ `{"id","en","th","note","status","v"}` |
| `examples/<level>.jsonl` | ประโยคตัวอย่าง `{"id","ja","th","status","v"}` |
| `audit/` | ผลการสุ่มตรวจโดยคน |

- `en`/`ja` คือข้อความต้นทาง ณ ตอนแปล ถ้าต้นทางเปลี่ยน คำแปลจะถูกตั้งเป็น `flagged` เพื่อตรวจใหม่
- สถานะ: `draft` → `auto_checked` (ผ่านตรวจอัตโนมัติ) → `verified` (คนตรวจแล้ว) หรือ `flagged`
